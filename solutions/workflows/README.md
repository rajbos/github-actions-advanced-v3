# Completed workflow references

These are complete reference implementations, not learner starting points. Use the matching file from `examples/workflows` first and consult this directory through the lab's collapsed solution section after attempting the task.

The baseline, broad issue observer and minimal local-emulator demo are intentionally the same in both sets: they are measurement/demo scaffolding, not implementation exercises.

Before any authorized reference run, adapt course-owned runner/image names, default branch, host and signer constraints; generate/review the execution lockfile and apply the lab's prerequisites and cleanup. Copy only one lab's selected files to `.github/workflows`, preserving filenames. Never bulk-enable these workflows or use them to bypass existing rules.

Validation must cover both this directory and the starters. Earlier test runs used the completed workflows; they do not prove that the current starter exercises were rehearsed.
